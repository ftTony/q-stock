- 排查：该骨架来自 `symbol-derivatives-panel.tsx` 的 `OptionsDerivativesBody` loadingMeta 分支（`.aw-deriv-skel-wrap`），与 footer 免责声明是 `SymbolDerivativesPanel` 内的 flex 兄弟。上一轮修复的 `.aw-deriv-skel-wrap > [role=status] > div:not(:first-child) > .aw-skel { flex:1 1 32px; min-height:32px }` 已覆盖此分支——截图为修复前状态。
- 额外加固：把 `.aw-deriv-skel-wrap > [role=status]` 的 `min-height:100%` 去掉（它与 footer 是兄弟，min-height:100% 相对整个 flex 父会把 footer 挤出视口），改为自然高度 + display:flex column，撑满交给外层 `flex-1`。`.aw-h5-skel-fill`（基本面等整屏骨架）保留 min-height:100%。
- Web 端零影响（max-width:1023px 作用域）。验证 tsc 通过。

## H5 从其它页面返回后 tab 高亮与内容脱节修复（仅移动端）
- 现象：截图显示切到「新闻」tab 后从其它页面返回，顶部 tab 高亮「新闻」，但主体却显示 K 线图。
- 根因：H5 有两套状态——tab 高亮由 `mobileSegment` 驱动（SymbolMobileQuickActions），主体内容由 `s.tab → panelTab` 驱动（SymbolTabsPanel）。正常点 tab 时 `onMobileSegment` 同时设两者，同步。但 `use-symbol-page.ts` 有个 effect 依赖 `initialQuote`，从其它页面返回同一标的时 initialQuote 引用变化触发 `setTab("chart")`，只重置了 `tab` 没同步 `mobileSegment`（仍是 news），导致高亮与内容脱节。
- 修复（仅 H5，Web 保留原行为）：
  - `use-symbol-page.ts`：`useSymbolPage` opts 加 `isDesktop?: boolean`；返回重置 effect 改为 `if (isDesktop) setTab("chart")`（Web 端返回仍重置 chart，行为不变）；H5 端不重置，tab 保持离开时值与 mobileSegment 一致。切标的重置本就由 `resetForIdentity` 同时处理 tab+mobileSegment，不受影响。
  - `symbol-page-client.tsx`：调用 `useSymbolPage` 时传 `isDesktop`。
- 验证：tsc --noEmit + 两文件 ESLint + store 单测 10/10 全通过。
