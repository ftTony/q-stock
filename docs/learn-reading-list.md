# 投资知识 — 推荐理财书籍与学习路线

> 配合 [投资知识内容规划](./learn-content-plan.md) 使用。  
> 用途：专栏可产出「书单总览 / 单书导读 / 学习路线」页；**推荐不等于荐股或保证收益**。  
> 选书原则：服务「冷静投、长期、风险与行为」；少选暴富学、喊单秘籍。

站内呈现建议（工程可后置）：

| 形态 | 路由建议 | 说明 |
|---|---|---|
| 书单总览 | `/learn/reading-list` | 分阶表格 + 链到单书导读 |
| 单书导读 | `/learn/book-[slug]` | 讲了什么 / 启发 / 下一步读什么 / 站内练习 |
| 学习路线 | `/learn/path-beginner` 等 或书单页内锚点 | 阶段目标 + 书 + 短文 + 工具 |

文末统一免责：个人阅读笔记向导读，不构成投资建议；请自行判断是否适合你。

## 1. 选书与导读写法

每本书固定四块（写入 Learn 短文或本书文档）：

1. **讲了什么** — 主题与结构，3～6 句  
2. **给人什么启发** — 可迁到交易/理财行为的要点（非操作指令）  
3. **适合谁 / 注意什么** — 门槛、时代局限、易误读处  
4. **站内怎么练** — 链到短文、Tools、模拟/复盘  

不写：具体买卖标的、跟书「抄作业」组合、承诺读完能盈利。

## 2. 推荐书单（核心 12 本）

按与钱力股气质的契合度精选；中英常用译名并列。可按季度加减，保持 **12±4** 本，避免书墙吓人。

### 2.1 入门 · 金钱观与行为（先建立态度）

#### 《金钱心理学》The Psychology of Money — Morgan Housel

| 项 | 内容 |
|---|---|
| **讲了什么** | 用故事讲财富与金钱决策：攒钱能力、运气与风险、知足与目标、时间的作用；强调行为往往比智商更影响结果。 |
| **启发** | 理财首先是行为问题；「足够」比「最多」更可执行；财富是看不见的（未花掉的钱）；长期一致比短期聪明重要。 |
| **注意** | 不是选股教程；故事化强，需自己提炼规则。 |
| **站内练习** | 短文 `calm-watching`、`less-is-more`；工具「复利」「定投」感受时间；每周 `/review` 只记行为不记面子。 |
| **导读 slug** | `book-psychology-of-money` |

#### 《小狗钱钱》— Bodo Schäfer（及常见中文版）

| 项 | 内容 |
|---|---|
| **讲了什么** | 用童话讲储蓄、复利、目标与金钱习惯；面向财商启蒙。 |
| **启发** | 先有记录与目标，再谈复杂产品；小额坚持可形成正反馈。 |
| **注意** | 偏少儿/入门隐喻，细节勿直接套到股票杠杆。 |
| **站内练习** | `/tools/compound`、`/tools/dca`；短文 `compound-tool-guide`。 |
| **导读 slug** | `book-puppy-money` |

#### 《思考，快与慢》Thinking, Fast and Slow — Daniel Kahneman

| 项 | 内容 |
|---|---|
| **讲了什么** | 双系统思维：直觉快速、理性缓慢；常见偏见（锚定、损失厌恶、过度自信等）。 |
| **启发** | 看盘时的「必须干一笔」多半是系统 1；清单与等待是系统 2 的外挂；亏损时加倍常是损失厌恶。 |
| **注意** | 学术偏厚，可跳读与投资相关章节；不是技术分析书。 |
| **站内练习** | `checklist-three`、`fomo-and-news`、`review-emotions`；下单前强制三问。 |
| **导读 slug** | `book-thinking-fast-slow` |

### 2.2 基础 · 市场、指数与长期

#### 《漫步华尔街》A Random Walk Down Wall Street — Burton Malkiel

| 项 | 内容 |
|---|---|
| **讲了什么** | 市场历史与泡沫、有效市场争论、各类分析流派局限；倡导分散与低成本长期投资（指数化思路）。 |
| **启发** | 短期价格难预测；成本与分散往往比「神操作」更可控；对技术/基本面都保持谦逊。 |
| **注意** | 版本多，读较新版；各国市场结构不同，结论迁移要谨慎。 |
| **站内练习** | `multi-market-101`；用 `/analysis` 理解「同业比较」而非预测；定投工具做假设而非回测神迹。 |
| **导读 slug** | `book-random-walk` |

#### 《共同基金常识》The Little Book of Common Sense Investing — John C. Bogle

| 项 | 内容 |
|---|---|
| **讲了什么** | 低成本指数基金、费用吞噬收益、长期持有与回归常识。 |
| **启发** | 先问成本与持有能否坚持，再问「明年暴涨标的」；简单策略需要纪律。 |
| **注意** | 语境偏美股基金；A 股/港股产品结构不同，只借「低成本+纪律」框架。 |
| **站内练习** | `/tools/dca`、`/tools/compound`；短文 `dca-tool-guide`。 |
| **导读 slug** | `book-bogleheads-common-sense` |

#### 《指数基金投资指南》— 银行螺丝钉（中文读者常用）

| 项 | 内容 |
|---|---|
| **讲了什么** | 指数基金是什么、如何定投、估值与网格等国内读者熟悉的方法框架。 |
| **启发** | 把「买股票」降维成可执行的定投计划；重视规则胜于感觉。 |
| **注意** | 估值与网格有失效期；本站不做历史回测承诺，导读须写「规则需自检」。 |
| **站内练习** | 定投/复利工具；`risk-before-size`；模拟盘练「按规则加减」而非追热点。 |
| **导读 slug** | `book-index-fund-guide-cn` |

### 2.3 进阶 · 价值、周期与风险意识

#### 《聪明的投资者》The Intelligent Investor — Benjamin Graham

| 项 | 内容 |
|---|---|
| **讲了什么** | 投资与投机区别、安全边际、市场先生、防御型/进取型投资者行为框架。 |
| **启发** | 价格与价值可能偏离；先求不败（安全边际与情绪管理）；程序与纪律重于听消息。 |
| **注意** | 原书案例老，读注释版；勿把公式当收银机；加密等资产不在原书框架内。 |
| **站内练习** | `/analysis` 同业对比；AI 读图要结构与失效，不要求「抄底指令」。 |
| **导读 slug** | `book-intelligent-investor` |

#### 《投资中最简单的事》— 邱国鹭

| 项 | 内容 |
|---|---|
| **讲了什么** | 用一线投研经验谈能力圈、商业模式、估值与安全边际等「简单但难执行」的事。 |
| **启发** | 把问题简化到可验证的少数变量；承认不懂比硬凑观点更重要。 |
| **注意** | 案例偏权益研究，不是短线教程。 |
| **站内练习** | `peer-compare`、`earnings-season`；对比篮固定 2–4 只深挖而非全市场扫描。 |
| **导读 slug** | `book-simplest-things-investing` |

#### 《周期》／《最重要的事》相关读法 — Howard Marks（建议以《周期》或《投资最重要的事》择一精读）

| 项 | 内容 |
|---|---|
| **讲了什么** | 信贷与情绪周期、风险的不对称显现、「现在所处周期位置」比点位预测重要。 |
| **启发** | 风险往往在众人无感时累积；乐观顶点与悲观谷底都要防极端仓位。 |
| **注意** | 偏机构与信用市场语境；个人用「仓位与预期」迁移即可。 |
| **站内练习** | `risk-before-size`、仓位工具；复盘问「我是否在追拥挤交易」。 |
| **导读 slug** | `book-howard-marks-cycles` |

#### 《随机漫步的傻瓜》Fooled by Randomness — Nassim N. Taleb

| 项 | 内容 |
|---|---|
| **讲了什么** | 运气与技能混淆、幸存者偏差、罕见事件对结果的主导。 |
| **启发** | 短期盈亏说明不了水平；要为「没见过的风险」留余地；慎把回测曲线当能力。 |
| **注意** | 文风尖锐；可与《黑天鹅》二选一深读，避免书单过载。 |
| **站内练习** | 模拟盘拉长周期再复盘；期权工具先看最大亏损；杠杆警示文。 |
| **导读 slug** | `book-fooled-by-randomness` |

---

### 2.4 交易心理与结构（谨慎推荐）

#### 《股票作手回忆录》Reminiscences of a Stock Operator

| 项 | 内容 |
|---|---|
| **讲了什么** | 以小说化传记写投机生涯：趋势、人性、大起大落。 |
| **启发** | 人性百年未变（恐惧贪婪）；投机成本极高；「按自己的系统」难在坚持。 |
| **注意** | **不是**操作手册；易被读成励志投机——导读必须强调反面教材属性。 |
| **站内练习** | `paper-review`：用模拟体会「冲动单」；禁止把回忆录情节当策略。 |
| **导读 slug** | `book-stock-operator` |

#### 《期权、期货及其他衍生产品》导读向（Hull）— 仅作「进阶索引」

| 项 | 内容 |
|---|---|
| **讲了什么** | 衍生品定价与风险的系统教材（极厚）。 |
| **启发** | 权利金、波动率、希腊值是风险语言；先懂亏在哪再谈策略。 |
| **注意** | **不建议新人通读**；站内只推「选读 + 期权估算工具」，导读页写清难度。 |
| **站内练习** | `/tools/options`；短文 `options-tool-guide`。 |
| **导读 slug** | `book-hull-derivatives-lite`（导读级，非全书摘要） |

## 3. 学习路线（推荐怎么读、怎么练）

三条主路线，可并行但**不要同时开三本厚书**。每阶段：目标 → 书 → Learn 短文 → 站内动作。

### 路线 A — 理财启蒙（约 2–4 周）

**目标**：建立金钱行为与复利直觉；尚不追求选股。

| 顺序 | 书 | Learn | 站内动作 |
|---|---|---|---|
| 1 | 《小狗钱钱》或《金钱心理学》 | `compound-tool-guide`、`calm-watching` | 复利/定投各算一版「假设」 |
| 2 | 《思考，快与慢》（跳读偏见章节） | `checklist-three`、`fomo-and-news` | 写一页「下单前三问」备忘 |
| 3 | — | `paper-review` | 模拟盘只做 **2～3** 笔计划内交易 + 一次复盘 |

**毕业标准**：能说清「我的风险预算」和「什么情况先停手」；不要求会看财报。

---

### 路线 B — 长期投资者（约 1–2 月）

**目标**：理解市场不可完整预测、成本与分散、多市场常识。

| 顺序 | 书 | Learn | 站内动作 |
|---|---|---|---|
| 1 | 《漫步华尔街》 | `multi-market-101`、`kline-basics` | 四个市场看板各浏览 10 分钟，只记差异 |
| 2 | 《共同基金常识》或《指数基金投资指南》 | `dca-tool-guide`、`risk-before-size` | 定投工具 + 仓位工具；自选不超过 10 只 |
| 3 | 《投资中最简单的事》 | `peer-compare`、`earnings-season` | `/analysis` 做 1 次同行对比笔记 |
| 4 | — | `watchlist-alerts`、`ai-chart-read` | 提醒只绑「失效条件」；AI 只问结构不求代码 |

**毕业标准**：能解释为何不把短期涨跌当能力证明；有一份书面定投/仓位规则（可极简）。

---

### 路线 C — 进阶冷静交易者（约 2–3 月，可选）

**目标**：安全边际与周期意识；交易心理；衍生品仅建立风险语言。

| 顺序 | 书 | Learn | 站内动作 |
|---|---|---|---|
| 1 | 《聪明的投资者》（选读） | `scenario-map`、`invalidation-habit` | 情景地图 → 纸面条件草案 |
| 2 | Marks《周期》或《最重要的事》 | `review-emotions` | 连续 4 周周复盘，标注情绪标签 |
| 3 | 《随机漫步的傻瓜》 | `leverage-warning` | 检查是否在用过高风险假设 |
| 4 | 《股票作手回忆录》（当案例） | `paper-review` | 对照书中冲动情节，列「我禁止的行为」 |
| 5 | Hull 导读级 + 站内期权工具 | `options-tool-guide` | 只算 long call/put 的打和与最大亏损 |

**毕业标准**：能独立完成「结构 → 价位 → 失效 → 风险预算」闭环；期权只做到「懂亏在哪」。

---

### 路线总览图

```text
路线 A 启蒙          路线 B 长期            路线 C 进阶（可选）
金钱观 / 偏见    →   市场谦逊 / 定投纪律  →  安全边际 / 周期 / 心理
     ↓                     ↓                        ↓
复利·定投·三问         多市场·对比·提醒           情景·复盘·期权风险
     ↓                     ↓                        ↓
少而认真的模拟    →   规则化自选与仓位      →   失效条件习惯化
```

三条路线的**共同终点**：不是「学会荐股」，而是「有可重复的冷静流程」。

## 5. 「别读什么」与书单边界（可写进 reading-list）

公开写清，减少误解：

- 承诺暴富、跟单密码、内幕暗示类  
- 把回忆录当今日可复制战法的读法  
- 未经验证的「必涨形态」图册当圣经  
- 与自身合规环境冲突的跨境杠杆教程（本站亦不提供真盘下单）
