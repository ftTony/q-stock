# 钱力股 / Q-Stock — 可落地路线图

> 把[现状](./product-status.md)与[机会清单](./product-opportunity-brainstorm.md)收成可执行切片。  
> 默认假设：**短期双线并行、叙事分清**——C 端补齐漏斗 + 源码交付打磨；中期只选一个「尖 fort」。

## 0. 决策结论（可改，改了要同步本文）

| 决策 | 当前默认 |
|---|---|
| 品牌边界 | 学习 / 投研终端；**不做默认实盘下单** |
| 主闭环 | 看盘 → 分析/AI → 模拟 → 复盘 |
| 短期商业 | C 端：讲清 Freemium（AI 配额 + BYOK）；B 端：打磨 `/pricing` 源码/部署包 |
| 中期尖 fort（三选一） | 待定：① A 股加深（扶摇）② L2 付费 ③ 投教/白标 |
| 明确后置 | 真单券商网关、社区帖流、无数据的资金流向大屏 |

若主线变更：只改「§0 + §3 中期」，不要重写短期清单。

---

## 1. 成功标准（3 个月可感知）

**产品**

- `/learn`、`/tools` 不再是 coming-soon，至少各有 1 条可走完的用户路径。  
- 新用户能在站内看到并走完：**加自选 → 设提醒或看 AI → 模拟一笔 → 打开复盘**。  
- 官网能分清两块入口：「立刻使用终端」vs「源码/部署咨询」。

**商业（选可测指标，不必全达标）**

- C 端：AI 试用转化（试用完后 BYOK 或邀请）、自选/提醒次日留存。  
- 源码：咨询线索数、演示环境可一键讲清模块边界。

---

## 2. 短期（约 4–8 周）— 三个必做切片

按依赖排序；每个切片都有「完成定义」，做完再开下一个增强项。

### 切片 A — 上线 Learn（约 1–2 周）

**目标**：投教内容可检索、可分享，支撑 SEO 与「冷静投」叙事。

| 步骤 | 动作 | 完成定义 |
|---|---|---|
| A1 | 打开 `/learn` 列表：读 `articles.ts`，去掉整页 coming-soon | 列表可见标题/摘要/标签 |
| A2 | 打开 `/learn/[slug]`：取消强制 redirect，渲染正文 | 至少 3 篇可打开的完整文 |
| A3 | 文末 CTA：去行情 / 去模拟 / 去工具 | 每篇至少 1 个产品内链 |
| A4 | 基础 SEO：metadata、sitemap 纳入 learn | 构建后 sitemap 含 learn URL |

**非目标**：评论区、课程付费、视频站。

**内容选题**：见 [投资知识内容规划](./learn-content-plan.md)（首发包 8 篇；类目 basics / tools / mindset）。

**依赖代码**：`src/lib/learn/articles.ts`、`src/app/[locale]/learn/**`

---

### 切片 B — 上线 Tools（约 1–2 周）

**目标**：算具可独立引流，并回链到模拟/个股。

| 步骤 | 动作 | 完成定义 |
|---|---|---|
| B1 | `/tools` 索引页：列出计算器卡片 | 不再 coming-soon |
| B2 | 实现 **4** 个：仓位风险、定投、复利、期权估算 | 输入 → 结果可截图，无后端也可；以 [PRD 索引](./prd/README.md) 为准 |
| B3 | 结果区 CTA：去模拟盘 / 去某市场看板（期权页另链仓位工具） | 有明确下一跳 |
| B4 | 免责声明块（非投资建议） | 文案与 disclaimer 口径一致 |

**非目标（切片 B）**：完整回测引擎、实盘同步持仓、期权链实盘报价/下单。  
规则实验室 / 回放见独立规划：[prd/strategy-and-backtest.md](./prd/strategy-and-backtest.md)（另排期，非本切片必做）。

**PRD**： [仓位](./prd/tool-position-sizing.md) · [定投](./prd/tool-dca.md) · [复利](./prd/tool-compound.md) · [期权](./prd/tool-options.md)

**建议拆分文件**：`src/components/tools/*`、可选 `src/lib/tools/*`（遵守 500 行文件上限）。

---

### 切片 C — 串主路径 + 讲清商业（约 2–3 周）

**目标**：闭环可被引导走完；Freemium / 源码叙事不打架。

| 步骤 | 动作 | 完成定义 |
|---|---|---|
| C1 | 产品内「首次引导」或空态引导：自选 → 提醒或 AI → 模拟 → 复盘 | 新号走一遍无需猜路由 |
| C2 | 情景地图 → 纸面条件单草案：打通现有雏形 | 从 AI 结果可生成/跳转模拟挂单草案（见 C2 与切片 D） |
| C3 | Settings / 用尽配额文案：免费次数、邀请、BYOK 三条出路写清 | 用户不被「不能用了」堵死 |
| C4 | 营销与 `/pricing`：分栏「在线使用」vs「源码部署」 | 两套 CTA，不混在一个按钮 |
| C5 | （可选）收盘自选摘要邮件：打开 worker digest 的用户可见开关 | 至少美股收盘一封可用 |

**非目标**：付费订阅计费系统（可先文案 + 邀请/BYOK；支付后置）。

---

### 切片 D — 个股工作台 + 模拟风控 P0（约 2–3 周，可与 C 后半并行）

**目标**：个股页终端化；AI 冷静层接入下单；模拟盘下单前风险可见。

| 步骤 | 动作 | 完成定义 |
|---|---|---|
| D1 | 个股布局：QuoteBar + 图区一体 + 右栏 Tabs（下单 / 冷静 / …） | 一屏内可见价、图、下单；见 [symbol-trading-ui](./prd/symbol-trading-ui.md) |
| D2 | 冷静 Tab：情景筹码 +「预填并去下单」（不自动提交） | 切回下单 Tab +「AI 草稿」横幅可撤销 |
| D3 | 下单前：风险摘要 + 情绪自检（软提示） | 符合 [risk-control](./prd/risk-control.md) **P0** 验收 |
| D4 | 分享：Facebook / X 等社交 + 复制链接 | 报价条旁可分享当前个股页 |
| D5 | （可选）衍生品 Tab 空态 + 链 `/tools/options` | 美/港显示 Tab；无假链、无期权下单 |

**非目标（本切片）**：L2 盘口实装、富途模拟切换、账户级硬熔断（风控 **P1**）、规则回测引擎。

**PRD**：[个股 UI](./prd/symbol-trading-ui.md) · [风控 P0](./prd/risk-control.md) · [高级盘/富途](./prd/symbol-advanced-and-futu-paper.md)（后置）

---

### 切片 E — 规则实验室（另排期，约 2–4 周，建议中期或短期有余力）

**目标**：可解释的策略模板 + 单标的规则回放；服务 Learn/模拟，非量化平台。

| 步骤 | 动作 | 完成定义 |
|---|---|---|
| E0 | P0：模板库 + 我的策略 + 模拟单策略标签 | 见 [strategy-and-backtest](./prd/strategy-and-backtest.md) P0 |
| E1 | P1：单标的日 K 异步回放（曲线 + 买入持有对照 + 免责） | Worker 跑、限流、不拖垮 Web |
| E2 | P2：双规则对比 / 参数小表 / 多标的篮 / 分享 / AI 解读 | 已落地，见 PRD P2 |

**非目标**：实盘自动交易、策略 IDE、全市场扫描回测。

**依赖**：切片 B 仓位工具文案互链；风控 P0 后再做「回放结果 → 模拟草稿」更稳。

---

## 3. 中期（约 2–4 月）— 只选一个尖 fort

完成短期后，用一周评审会三选一（或明确「继续只打磨短期」）。

### 选项 ① A 股加深（扶摇）

| 项 | 内容 |
|---|---|
| 为何 | A 股用户与国内叙事；代码已在、路由关闭 |
| 要做 | 路由解禁、设置项恢复、failover 实测、合规文案复核 |
| 完成定义 | CN 看板/个股在扶摇启用时稳定；失败自动回退；设置可开关 |
| 风险 | 供应稳定性、合规展示、密钥与限流 |

### 选项 ② L2 / 高级行情付费

| 项 | 内容 |
|---|---|
| 为何 | `/advanced-quotes` 已有故事；可卖高客单 |
| 要做 | 明确数据源与权限模型；付费或授权开通；个股页深度档位 |
| 完成定义 | 未授权看不到 L2；授权后有可演示深度；账单或授权码可追溯 |
| 风险 | 数据成本、法务、与「学习终端」定位的张力 |

### 选项 ③ 投教 / 白标

| 项 | 内容 |
|---|---|
| 为何 | Learn + paper + review 天然适配；贴近源码客户 |
| 要做 | 去品牌主题包、部署手册、（可选）班级/作业最小集 |
| 完成定义 | 一份「白标交付清单」可按清单装出无钱力股品牌的实例 |
| 风险 | 定制爆炸；需严格范围与工时计价 |

**并行上限**：中期尖 fort **最多 1 个**；另一条只做文档级预研，不进主分支大功能。

## 4. 源码 / 部署线 — 可与短期并行的交付清单

不依赖 Learn/Tools 全部完成，可穿插打磨：

| # | 交付物 | 完成定义 |
|---|---|---|
| S1 | 模块边界一页纸 | 行情 / AI / 模拟 / worker / 邮件各自依赖什么 env |
| S2 | `.env.example` + 部署检查表对齐 | 新机器按文档 1 小时内起 web+db+worker |
| S3 | 白标开关清单 | Logo、站名、主题色、是否隐藏定价页 |
| S4 | Demo 脚本 | 10 分钟演示：看板 → 个股 AI → 模拟 → 复盘 → Settings BYOK |
| S5 | 售后边界 | 含什么升级、不含什么定制；避免卖成无限运维 |

对应入口：`/pricing`、[deployment.md](./deployment.md)、[getting-started.md](./getting-started.md)。

## 7. 验收检查表（发布前勾选）

**Learn / Tools**

- [ ] `/learn`、`/tools` 非 coming-soon  
- [ ] 至少 3 篇 learn；4 个 tools（仓位 / 定投 / 复利 / 期权）可完整使用且符合各自 PRD 验收  
- [ ] 每条路径有回产品 CTA + 免责声明  

**主闭环**

- [ ] 新用户空态能发现自选 / 模拟 / 复盘  
- [ ] AI 配额用尽有邀请或 BYOK 出路  
- [ ] 模拟成交后能打开 `/review` 并看到有意义输出  

**叙事与交付**

- [ ] 首页或定价页分清「在线用」与「源码部署」  
- [ ] Docker / env 文档按检查表可冷启动  
- [ ] 大陆合规与「非投资建议」文案未回退  

**工程卫生**

- [ ] 新增页面遵守 `src/**/*.{ts,tsx}` 500 行上限，大页已拆 panel/hooks  
- [ ] 无把实盘 gateway 误接到默认交易路径
