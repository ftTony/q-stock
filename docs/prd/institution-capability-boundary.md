| 项 | 内容 |
|---|---|
| 产品 | 钱力股 / Q-Stock |
| 人设 | **教育机构、投顾工作室、小型团队**需要「可交付终端」；**不是**公募/券商/对冲基金 OMS |
| 用途 | 对照机构真实需求砍伐；区分 C 端订阅 vs 源码/白标/定制；避免被拉成机构交易台 |

## 1. 定位一句话

机构要的是 **可品牌化的学习/投研壳 + 过程纪律 + 可部署交付**；不是低延迟撮合、多账户 OMS、监管报送或券商级合规栈。

**与 C 端边界**

| | C 端个人（波段/学习） | 机构侧（本文） |
|---|---|---|
| 主交付 | 在线 Free/Pro/BYOK | 源码 / 私有部署 / 白标 / 定制 |
| 主闭环 | 看盘 → 分析 → 模拟 → 复盘 | 同左，可去品牌、可按席位授权 |
| 明确不是 | 实盘券商 App | 机构 OMS / EMS / 清算 |

**成功标准（验收口语）**

有一份白标交付清单：换 Logo/站名/主题、藏定价页、配好 env 后，能装出无「钱力股品牌」且仍走通模拟→复盘主路径的实例。

## 2. 机构常见能力全景（对照用）

以下按机构真实工作流列出；**不等于我们都做**。后文用「我们做 / 以后做 / 不做」裁剪。

### 2.1 组织与权限

| 能力点 | 机构为何需要 |
|---|---|
| 多租户 / 多组织 | 学校、工作室、分公司隔离数据 |
| 席位与角色（学员 / 教练 / 管理员） | 作业批改、只读旁观、重置模拟盘 |
| SSO（企业微信 / Google Workspace / SAML） | 统一身份，少一套密码 |
| 审计日志（谁改了什么） | 内控与纠纷追溯 |
| 数据驻留与私有化 | 不出境 / 不上公有云 |

### 2.2 投研与协作

| 能力点 | 机构为何需要 |
|---|---|
| 共享自选 / 共享研究笔记 | 团队同一观察池 |
| 研报或课包挂标的 | 投教作业、内训材料 |
| 只读旁观学员模拟盘 | 教练点评过程而非喊单 |
| 统一免责与合规页可配置 | 各司法辖区文案不同 |

### 2.3 交易与风控（机构真盘语境）

| 能力点 | 机构为何需要 |
|---|---|
| 多账户 / 子账户 / 策略账户 | 资金与策略隔离 |
| OMS：下单路由、撤改、拒单原因 | 接券商或柜台 |
| 预交易风控（限额、黑白名单、集中度） | 合规与风控岗 |
| 成交回报、持仓、估值、PnL 归因 | 中后台 |
| 算法单 / TWAP·VWAP | 大单执行 |
| 连接 FIX / 柜台 / 托管 | 生产交易 |

### 2.4 数据、合规与运营

| 能力点 | 机构为何需要 |
|---|---|
| 行情授权与转发合规 | 牌照、交易所协议 |
| 监管报送、Suitability、适当性 | 持牌销售 |
| SLA、监控、灾备 | 生产级可用性 |
| 按席位 / 按组织计费与合同 | 采购流程 |
| 导出与 API（持仓、成交、审计） | 对接内部 BI |

## 3. 我们做（机构可交付、服务投教/白标）

对齐路线图尖 fort「投教/白标」与 `/pricing` 源码分栏；**复用 C 端闭环，不新开 OMS 产品线**。

| 能力点 | 说明 | 现状粗标 |
|---|---|---|
| 源码 / Docker 私有部署 | 模块边界可讲清；自备 Key | `/pricing` 下半 + Docker |
| 白标开关 | Logo、站名、主题色、藏定价页 | 路线图 S3 清单候选 |
| 学习闭环可演示 | 自选 → AI/计划 → 模拟 → 复盘 | C 端已有骨架 |
| 模拟盘过程资产 | 成交日志、规则标签、复盘 | 已有；适合课堂/训练 |
| 冷静 AI + BYOK | 机构自带模型 Key，不占我方配额叙事 | 设置页 BYOK |
| Learn / Tools 可去品牌嵌入 | 投教内容与算具作课包零件 | 已有路由 |
| 合规文案可配置入口 | 免责、非投资建议、地区提示 | 部分静态页；白标时加强 |
| 定制咨询入口 | mailto / 商务分栏，与 C 端 Pro 分 SKU | 已有叙事要求 |
| 健康检查 / Worker 边界文档 | 交付时可运维 | 见架构与源码交付切片 |

**优先级（机构线）**

1. **P0**：交付清单可装机演示 + C/B 叙事分栏不混 SKU  
2. **P1**：白标开关落地、席位/学员角色若有明确付费客户再做  
3. **P2**：共享自选/教练旁观等协作；有合同再排

## 4. 以后做（有明确机构客户或合同再开）

| 能力点 | 备注 |
|---|---|
| 学员 / 教练 / 管理员三角色 | 投教刚需；无客户则不做空壳权限系统 |
| 教练只读旁观模拟盘 + 批注 | 强化「过程」交付 |
| 组织级模拟重置与作业模板 | 班级开课 |
| SSO（先 Google / OIDC，再 SAML） | 企业采购常见门槛 |
| 操作审计日志（管理动作） | 轻量即可，非监管级 |
| 共享自选池 / 共享研究卡只读 | 小团队协作 |
| 按席位授权与合同报价页 | 商务流程，非 C 端 Stripe 套娃 |
| 成交/复盘导出（CSV） | 对接机构内部报表 |
| 多语言白标默认集 | 海外投教 |

## 5. 不做（机构真盘 / OMS 栈）

| 明确砍掉 | 原因 |
|---|---|
| OMS / EMS、算法单、FIX 柜台接入 | 另一条产品线；人员与牌照成本不匹配 |
| 真金多账户、托管、清算、估值引擎 | 中后台系统，非本仓库目标 |
| 监管报送、适当性双录、持牌销售流程 | 合规产品，不是学习终端 |
| 代表客户转发付费行情作 SaaS 转售 | 协议与合规风险；倾向 BYOK / 私有 Key |
| 机构级预交易风控引擎（集中度、黑白名单生产闸） | 见 [risk-control](./risk-control.md) 非目标；模拟软提示足够 |
| 低延迟行情竞赛、同址撮合 | 与学习型定位冲突 |
| 用 C 端 Pro 订阅冒充机构席位合同 | GTM 分栏；见品牌增长计划 |
| 无合同先做的多租户大台 | 避免空转架构 |

## 6. 评审用检查句

开「机构向」需求前先过四句；任一为「否」则默认不做或打进「以后做」：

1. 是否仍落在 **可部署的学习/投研壳**，而不是 OMS？  
2. 是否有 **明确买方**（合同或付费试点），还是想象中的机构？  
3. 是否与 C 端 Pro **分入口、分 SKU、分文案**？  
4. 是否强化课堂/训练的 **过程纪律**（模拟、规则、复盘），而非代客下单？

## 8. 非目标（本文自身）

- 不替代具体白标交付清单的逐步勾选（见路线图 S 系列）。  
- 不承诺任何司法辖区的持牌或行情转授权。  
- 不把「机构常见能力全景」当作 backlog 全量排期。
