## 1. 定位一句话

学习型投研终端：强化 **看盘 → 分析/AI → 模拟 → 复盘**；用规则与过程纪律替代喊单与券商全能壳。

**成功标准（验收口语）**

新用户能在约两周内反复走通：自选 → 计划/冷静 AI → 模拟一笔并挂规则标签 → 打开复盘改规则。

**优先级（砍需求时）**

1. **P0**：闭环可引导走完 + 风控 P0 + 情景→草案  
2. **P1**：研究卡/计划可见、复盘质量、工具↔模拟互链  
3. **P2**：中期只选一个尖 fort（见路线图 §3），其余仍属「以后做 / 不做」

## 4. 不做（写进边界）

| 明确砍掉 | 原因 |
|---|---|
| 默认实盘下单、跟单社区 | 学习终端 + 合规边界 |
| 荐股信号会员、涨跌情绪标签产品化 | 与冷静投冲突 |
| 量化 IDE、全市场扫描回测、策略商城 | 非量化平台人设 |
| 日内专用：DOM、刷单快捷键、超低延迟竞赛 | 波段人设用不上 |
| 无数据的资金流大屏 / 热力堆砌 | 糊主路径 |
| 完整期权链实盘报价与下单 | `/tools/options` 估算即可 |
| 课程付费视频站、帖流社区 | Learn 非内容站 |
| 源码 SKU 与 Pro 混成同一售卖单元 | GTM 叙事打架 |
| 真券商保证金 / 强平 / 机构 OMS | 见风控非目标 |

---

## 5. 评审用检查句

开需求前先过三句；任一为「否」则默认不做或打进「以后做」：

1. 是否强化 **看盘 → 分析 → 模拟 → 复盘**？  
2. 两周内能否在垂直场景可演示？  
3. 是否避免变成券商全能壳或量化 IDE？

---

## 6. 非目标（本文自身）

- 不替代各功能 PRD 的交互与验收细则。  
- 不规定中期尖 fort 最终选型（仍由路线图评审会决定）。  
- 不承诺行情完整度或收益。
