## 1. 定位一句话

**专业金融终端（学习纪律版）**：终端级看盘与工作台密度，服务 **看盘 → 分析/AI → 模拟 → 复盘**；用规则与过程资产替代喊单、跟单与券商全能堆砌。

与「券商 App」的差别不在「有没有 K 线」，而在：

| | 券商全能终端（我们不对齐） | 本产品要对齐 |
|---|---|---|
| 主任务 | 成交与账户资产 | **过程纪律**（计划 → 模拟 → 复盘） |
| 行情深度 | L1→L2→逐笔默认堆满 | L1 扎实；L2/深度**分期、可付费、可关** |
| 下单 | 默认实盘 | **默认模拟**；实盘网关明确后置 |
| 策略 | 条件单 / 算法单为主 | **规则标签 + 回放 + 偏差**，非量化 IDE |
| 成功标准 | 成交量、留存下单 | 两周内能反复走完闭环 |

**成功标准（验收口语）**

1. **闭环**：新用户约两周内反复走通：自选 → 计划/冷静 AI → 模拟一笔并挂规则标签 → 打开复盘改规则。  
2. **终端感**：个股一屏内价、图、计划/下单可读；浮层/下拉不破壳；横滚不抖；小机不炸。  
3. **边界清楚**：对外从不默认承诺「实盘一键下单」或「L2 免费全家桶」。

## 2. 演进分期（金融终端产品怎么长）

不做「一次性复刻 Longbridge Pro」。按终端能力成熟度分期；**每一期都必须还能走通主闭环**。

```text
T0 学习投研壳（现状骨架）
  → T1 专业终端工作台（密度 / 稳定性 / 主路径）
  → T2 行情与衍生品加深（可选付费深度）
  → T3 强用户布局与多屏
  → T4+ 可选实盘网关 / 投教白标（尖峰二选一或后置）
```

| 期 | 产品含义 | 完成定义（口语） | 与路线图 |
|---|---|---|---|
| **T0** | 多市场 L1 + 模拟 + AI + 复盘骨架 | 主路径可演示 | 现状 / 短期切片 |
| **T1** | **专业金融终端壳**：个股工作台、图表保活、期权链可用、设置/凭证稳、终端视觉一致 | 「像终端，而不像功能堆砌页」 | 切片 D + UI/性能债 |
| **T2** | 深度行情与衍生品叙事可卖 | 未授权看不到 L2；授权后可演示；期权链不假下单 | 中期尖峰候选「L2」 |
| **T3** | 多图/布局/快捷键服务波段对比 | 1/2/4 格稳；布局可记；不挡主闭环 | [multi-chart-compare](./multi-chart-compare.md) 增强 |
| **T4+** | 实盘网关 **或** 投教白标（仍非 OMS） | 有独立评审；默认不同时开两条大线 | 路线图尖峰 / 后置 |

**原则**

- **先 T1 再堆深度**：没有稳的工作台，L2 只是更贵的噪声。  
- **深度可关**：高级行情走 `/advanced-quotes` 与授权，不绑架 Free 主路径。  
- **实盘永远显式**：任何「接券商」须单独 PRD + 合规评审，不得从模拟按钮静默升级。

## 3. 我们做（主路径，该深挖）

### 3.1 终端工作台（T0→T1 核心）

| 能力点 | 说明 | 现状粗标 |
|---|---|---|
| 多市场看板 + 个股 L1 | 美 / 港 / A / 加密，统一壳 | 已有 |
| 个股工作台 IA | 报价条 + 主图 + 右栏（计划 \| 下单 \| 复盘）；辅层折叠 | 见 [symbol-trading-ui](./symbol-trading-ui.md) |
| 自选 + 价格提醒 | 自选主入口；提醒次级 | 已有 |
| 多周期 K + 常用指标 | 服务波段结构；不堆指标超市 | 已有 |
| 图表保活 / 形态切换 | 切 Tab 不重挂引擎；蜡烛/面积可记 | 进行中 |
| 实时报价通道 | WS 引用计数、晚订阅补帧；状态可见 | 骨架已有 |
| 期权链（只读 + 策略工具抽屉） | T 字报价、H/V 滚稳定；估算/情景，非实盘期权下单 | 已有；继续打磨稳定 |

### 3.2 纪律闭环（产品差异化，各期都要保住）

| 能力点 | 说明 | 现状粗标 |
|---|---|---|

| 规则模板 + 订单标签 + 教学向回放 | 纪律闭环；非量化 IDE | 规则实验室已上 |
| 日 / 周过程复盘 | 事实 → 偏差 → 规则调整 | 已有 `/review` |
| 研究卡 / 计划栏（挂标的） | Pro 锚过程资产 | 见 [c-end-billing](./c-end-billing.md) |
| 仓位 / 定投 / 复利 / 期权估算 | 算完 CTA 回模拟或个股 | 已有 `/tools` |

### 3.3 分析与对照

| 能力点 | 说明 | 现状粗标 |
|---|---|---|
| 同行对照 / 对比篮 | 分析页主任务 | 已有 |
| 多图同屏（多标的） | 1/2/4 格共享周期；分析篮可带入 | 见 [multi-chart-compare](./multi-chart-compare.md) |

**优先级（砍需求时）**

1. **P0（T1）**：闭环可引导走完 + 工作台稳定（图/链/浮层/设置）+ 风控 P0 + 情景→草案  
2. **P1**：研究卡/计划可见、复盘质量、工具↔模拟互链、行情状态可感知  
3. **P2（T2/T3）**：中期只选一个尖峰（L2 / A 股加深 / 白标），其余进「以后做」

## 5. 不做（写进边界）

| 明确砍掉 | 原因 |
|---|---|
| 默认实盘下单、跟单社区 | 学习纪律终端 + 合规边界 |
| 荐股信号会员、涨跌情绪标签产品化 | 与冷静投冲突 |
| 量化 IDE、全市场扫描回测、策略商城 | 非量化平台人设 |
| 日内专用：DOM、刷单快捷键、超低延迟竞赛 | 波段人设用不上；工程与合规成本畸高 |
| 无数据的资金流大屏 / 热力堆砌 | 糊主路径 |
| 完整期权链**实盘**报价与下单 | 链上只读 + `/tools/options` 估算 |
| 课程付费视频站、帖流社区 | Learn 非内容站 |
| 源码 SKU 与 Pro 混成同一售卖单元 | GTM 叙事打架 |
| 真券商保证金 / 强平 / 机构 OMS / EMS / 清算报送 | 见机构边界非目标 |

**「金融终端」≠「券商 OMS」**：终端指工作台密度、行情体验、过程工具；不指持牌交易中台。

## 6. 评审用检查句

开需求前先过下列句子；关键路径题任一为「否」则默认不做或打进「以后做」：

1. 是否强化 **看盘 → 分析 → 模拟 → 复盘**？  
2. 是否提升 **终端感或稳定性**（密度、浮层、滚动、实时态、小机），而不是堆第三个行情玩具？  
3. 两周内能否在垂直场景可演示？  
4. 是否避免变成券商全能壳、量化 IDE 或信号会员？  
5. 若涉及 L2 / 实盘 / 白标：是否落在当前路线图尖峰，且有独立完成定义？

## 8. 非目标（本文自身）

- 不替代各功能 PRD 的交互与验收细则。  
- 不规定中期尖峰最终选型（仍由路线图评审会决定）。  
- 不承诺行情完整度、收益或实盘开通时间表。  
- 不把「看起来像券商」当作验收标准；验收以闭环 + 终端稳定为准。
