# 个股页 UI 改版 — 规则驱动的交易工作台

> 状态：**实现中**（工作台骨架已落地；**交易抽屉 IA P0** 见 §4.5.1，票头/折叠账户/可读策略/提交反馈已落地，按 §8 清单回归）  
> 目标：把 `/symbol/[assetType]/[symbol]` 从「看盘 + 下单」收成 **简洁、精专的规则驱动交易台**：看清价与图的同时，能在行动前写清/绑定规则、在本标的上看历史代价、模拟执行后对照偏差并修正规则。  
> 产品主张与分期：[策略与回测方向](../strategy-backtest-direction.md) · [策略与回测 PRD](./strategy-and-backtest.md) · [交易员能力边界](./trader-capability-boundary.md)  
> 配套能力：[symbol-advanced-and-futu-paper.md](./symbol-advanced-and-futu-paper.md) · [行情 AI 功能](../行情AI功能.md) · [模拟盘风险控制](./risk-control.md)  
> 技术参考：[financial-chart-tech.md](../financial-chart-tech.md) · [longbridge-web-trade-tech.md](../longbridge-web-trade-tech.md)

**核心闭环（个股页必须可走完，不强制跳走）：**

```text
明确规则 → 历史回放 → 看见收益与风险的交换 → 模拟执行 → 复盘执行偏差 → 修正规则
```

## 1. 现状问题

对照当前实现（[`symbol-page-client.tsx`](../../src/components/symbol/symbol-page-client.tsx)）与截图观感：

| 问题 | 表现 | 对闭环的伤害 |
|---|---|---|
| 主次是「行情」不是「计划」 | 右栏默认「行情」；盘口空态占半栏 | 行动前没有「规则先于结论」 |
| 规则不可见 | 无当前生效规则 / 入场·退出·仓位边界 | 下单像临场拍脑袋 |
| 回放与个股脱节 | 完整规则编辑/回放在 `/strategies` | 看不到「这条规则在这只票上的代价」 |
| 复盘不在当场 | `/review` 独立；右栏偏持仓列表 | 模拟后难立刻对照是否守规则 |
| 信息层级碎 | Header、图、提醒、Tabs、右栏各自 `qt-panel` | 显「堆功能」，不精致 |
| 密度与工具散落 | 大 padding；周期/指标/提醒分行 | 专业终端应「紧、齐、数字对齐」 |
| AI 与纪律脱节 | FAB 孤岛；冷静情景与下单/规则弱连接 | 「削弱贪婪恐惧」停在口号 |

**改版原则**：一张主屏 = **报价条 + 主图（可叠规则价位）+ 右栏（计划 | 下单 | 复盘）**；盘口/分笔为行情辅层；资讯/财报进次级区。AI **服务计划核对、草稿预填与复盘解释**，不另起营销墙，不自动下单。

## 2. 设计目标与非目标

### 目标

- **专业**：价格、涨跌、图、规则边界一眼可读；数字一律 `tabular-nums`
- **精致 + 好用 + 简洁**：默认一屏完成「看图 → 对照规则 → 挂模拟单」；次级折叠；一层边框、少套娃
- **规则驱动**：右栏默认「计划」；下单必能挂策略标签；本标的可触发有限回放并并列收益与风险
- **复盘在场**：本标的模拟单 vs 规则版本的偏差可见，并可链到「修正规则（新版本）」
- **AI 融合**：问股、冷静情景、情绪自检嵌在下单动线；语气冷静，不荐股、不真下单指令
- **克制**：沿用 `--up` / `--down` / `--brand` / `--panel`；无炫光、紫渐变、厚阴影

### 非目标

- 不做 Longbridge Pro 级多屏工作站一次性复刻
- 不做实盘下单 UI（模拟盘标识要清晰）
- **不做**「AI 说买就买」一键市价；情景草稿仅限价/止损，且须用户确认
- **不做**个股页内完整策略编辑器（复杂编辑仍在 `/strategies/[id]`；页内只做绑定、摘要、轻量改参入口）
- 不做策略收益排行榜或「照做就能多赚」话术
- 不改营销落地页视觉语言（个股页可略「终端化」，背景更素）

## 3. 产品 × 信息架构

### 3.1 闭环如何落在个股页

| 闭环步骤 | 个股页落点 | 深度能力所在 |
|---|---|---|
| 明确规则 | 右栏 **计划**：绑定模板/已有策略；摘要入场·退出·仓位·失效价 | `/strategies` 完整编辑 |
| 历史回放 | 计划内「在本标的回放」；主图叠买卖点/失效线 | Worker + `/api/strategies/.../replay` |
| 收益与风险交换 | 回放结果条：收益 **与** 最大回撤、交易次数、相对买入持有并列；默认完整区间 | 回放报告存档 |
| 模拟执行 | 右栏 **下单**：策略标签 + 冷静预填 + 情绪自检 | 纸面/富途模拟 |
| 复盘执行偏差 | 右栏 **复盘**：本标的成交 vs 当时规则版本 | `/review` 作跨标的总览 |
| 修正规则 | 复盘/计划内「开新版本」；新旧报告分开展示 | 策略版本史 |

### 3.2 桌面（≥1280px）— 主工作台

```text
┌─ Watchlist（可拖宽，默认开）─┬─ QuoteBar（40px，与左栏顶齐）────────────────┤ Dock │
│ 自选 · 管理图标 · 收起        │ 代码 NAME 价 涨跌% │ Tabs │ 规则徽标 │ 分享 │ 40px │
│ 名称代码 | 最新价 | 涨跌幅   ├─ Chart + 右栏计划/复盘/行情 ────────────────┤ 图标 │
│ 列表…                         │  下单/新闻/公告/AI → 点 Dock 出抽屉        │ 条   │
└───────────────────────────────┴────────────────────────────────────────────┴──────┘
```

- **左栏自选**：全高；顶栏与 QuoteBar 同高对齐；中间竖线可拖宽；收起后 QuoteBar 左侧「列表+心」再展开（不占用右侧 Dock）
- **右侧 Dock**：交易 / 新闻 / 公告 / AI → **抽屉**；不占主 Tab
- **右栏主 Tab**：计划 | 复盘 | 行情（下单改走 Dock 抽屉）

| Tab / 入口 | 职责 |
|---|---|
| **计划**（默认） | 当前规则摘要、本标的回放入口与结果条、链到策略详情 |
| **复盘** | 本标的近期模拟 vs 规则；偏差类型；修正入口 |
| **行情** | 盘口 / 分笔等 |
| **Dock · 下单** | 模拟表单 + 策略标签 + 冷静预填（抽屉） |

盘口 / 分笔：右栏「行情」或主图下方折叠条。资金 / 卖空 / 筹码仍在次级 Tab。

### 3.3 平板（768–1279）

- 右栏改为 **底部抽屉**：`计划 | 下单 | 复盘`
- 盘口/分笔进抽屉内「行情」子段或图下折叠
- QuoteBar 保留规则徽标 + AI 问股

### 3.4 手机（&lt;768）

```text
QuoteBar（两行：价+涨跌+规则徽标 / 关键指标 + AI）
ChartToolbar（横向滚动）
MainChart（约 40vh）
Segment: 计划 | 下单 | 复盘 | 行情 | 更多
Secondary Tabs（横向滚动）
FAB：仅「AI 问股」二次入口（与 QuoteBar 同源）
```

## 4. 组件清单与视觉规格

### 4.1 QuoteBar

| 元素 | 规格 |
|---|---|
| 代码 | 14–15px semibold，等宽感 |
| 名称 | 13px muted，truncate |
| 最新价 | 22–24px semibold tabular；涨跌色跟随用户设置 |
| 涨跌 | 13px，与价同色 |
| OHLC/量 | 11–12px；桌面一排，手机隐藏次要项 |
| **规则徽标** | 已绑定：小胶囊显示策略短名（点按 → 右栏切「计划」）；未绑定：muted「未绑定规则」文字链 → 计划 Tab |
| 操作 | 分享、自选、**AI 问股** |
| 分享 | Facebook / X / LinkedIn / WhatsApp / Telegram / 复制链接 / 系统分享；文案为代码+价+站名，非荐股 |

去掉：大面积指标卡片墙、与价同级抢视线的 News/Social 进度条（舆情进次级或概览一行）。

### 4.2 ChartToolbar

- 高度固定，底部分割线 `1px var(--border)`；与主图 **合成一块**，外框最多一层
- 周期：`分时 | 1m | 5m | D | W? | Q | Y`
- 指标：幽灵按钮，选中 = brand-soft
- **行情**：下拉或 toggle「盘口 / 分笔」控制图下折叠条，**不**占用右栏主 Tab

### 4.3 MainChart

- 高度：`min(580px, 54vh)` 桌面
- 加载：骨架条，不要整块居中大字 Loading
- 十字线/坐标：10–11px muted
- **规则叠加（P0 可先失效线/限价虚线；P1 加回放买卖点）**
  - 失效价、计划限价：虚线 + 右侧短标签
  - 回放成交：小三角/点，hover 显示规则触发说明
  - 不自动改用户主图周期；回放默认用日 K 区间（与策略 PRD 一致）

### 4.4 RightRail — 计划（默认）

```text
┌─ 当前规则 ─────────────────────────────────────┐
│ 名称 · 版本                                    │
│ 入场：…   退出：…   仓位：≤x%   失效：价/条件   │
│ [更换] [在策略实验室编辑]                       │
├─ 本标的回放 ───────────────────────────────────┤
│ [运行回放]  区间默认近 N 根日 K（与 PRD 上限一致）│
│ 结果条（风险先于收益视觉权重）：                 │
│   最大回撤  xx%  ·  交易次数  n  ·  持仓天数中位 │
│   累计收益  xx%  ·  vs 买入持有  xx%            │
│ 一行假设：手续费/滑点/成交时点（可展开）         │
│ [查看完整报告] → 策略详情/报告                  │
├─ 空态（无规则）────────────────────────────────┤
│ 「先选或写一条规则，再看历史代价」               │
│ [选用模板] [从我的策略绑定]                     │
└────────────────────────────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 默认 Tab | 进入个股页右栏默认 **计划**（本地可记「上次停留在下单」但不改产品默认叙事） |
| 不自动下单 | 回放结果可「生成模拟单草稿」→ 切到下单并预填；须用户确认 |
| 文案 | 禁止「稳赚」「照此即可」；结果脚注：教育/研究用途，不构成投资建议 |
| 容量 | 回放走限流 API / Worker；页内只展示摘要，不在请求路径扫全市场 |

### 4.5 RightRail / Dock — 下单

> 载体：桌面为 **Dock「交易」抽屉**（或右栏「下单」Tab，同一套 `TradePanel`）；标题旁 **「模拟」** 徽标（富途模拟上线后改「富途模拟」）。  
> 定位：**模拟执行站**——把计划规则变成可复盘的一笔过程资产；非券商全能票、非下单游戏。  
> 边界：见 [trader-capability-boundary](./trader-capability-boundary.md)；风险计算与账户规则见 [risk-control](./risk-control.md)。

#### 4.5.1 交易抽屉 IA（P0）— 消 demo 感

**问题（对照现状票）**：字段多但主路径糊——票头标的弱、策略显示内部 ID、账户四格抢视线、过程纪律像附录、提交后无当场反馈。  
**P0 目标**：新人 30 秒内能说出「买哪只、是模拟、挂了哪条规则、风险有没有定义」。

```text
┌─ A. 票头（固定，~48–56px）──────────────────────────┐
│ 代码  NAME   最新价  涨跌%     [模拟]            [×] │
│ 规则行：策略短名·版本  |  未绑定 →「去计划绑定」（不阻断）│
├─ B. 下单主路径（唯一编辑面）──────────────────────────┤
│ 买 | 卖（segment；买=--up 轻底，卖=--down 轻底）      │
│ 订单类型 · 数量 ·（限价/止损价）· 买一/卖一可点回填   │
│ 失效价（可选）· 策略标签（可读短名，禁裸 cuid）       │
│ 风险摘要（名义占权益% · 有无失效/止损）·「打开仓位工具」│
│ 情绪自检（默认折叠一行；展开见 §4.9-C）               │
│ 预估金额 + 全宽 CTA「买入」/「卖出」                  │
├─ C. 账户与过程（次级，默认折叠）──────────────────────┤
│ 一行摘要：权益 · 可用 · 单票占比（点开或去 /portfolio）│
│ 本标的未成交单（短列表，可撤）                        │
└──────────────────────────────────────────────────────┘
```

| 区块 | 规则 |
|---|---|
| **A 票头** | 必须锚定当前 `symbol`（代码+价+涨跌）；禁止空锚/「0」占位；价 `tabular-nums`、涨跌色跟用户设置 |
| **规则行** | 有绑定：短名可点 → 切计划 Tab；无绑定：muted 链「建议先在计划绑定规则」——**不阻断**下单 |
| **B 主路径** | 一屏一主任务：填单 → 看见风险 → 确认；输入统一 h-8/h-9 |
| **策略标签** | 下拉展示**可读名称**（可附版本）；「仅本单更换」允许；空选项文案「本单不挂标签」 |
| **风险摘要** | 贴 CTA 上方；无失效价时保留「风险未定义」中性句；触碰软阈值黄字，硬上限见 risk-control P1 |
| **情绪自检** | 默认折叠为「可选 · 标记下单原因」；展开后中性芯片；写入订单，不指责 |
| **冷静 / 问股** | 不占主路径整段；入口收成链或折叠「冷静预填」（§4.9-B），禁止 AI「立即市价」 |
| **C 账户** | 权益/可用/敞口/单票占比 **默认折叠**；展开才四格；详情进 `/portfolio` |
| **提交反馈** | 成功：顶栏 Toast 或票内结果条「模拟已成交 / 已挂单」+「查看本标的复盘」；失败：可读错误，不静默 |

**P0 明确降权 / 不做**

| 项 | 处理 |
|---|---|
| 账户四格常驻展开 | 改折叠摘要 |
| 策略下拉裸 ID（如 cuid） | 禁止进 UI；只存 id、显名称 |
| 情绪区与「问股」并排抢 CTA | 问股次级；自检折叠 |
| 默认市价强化「点一下就买」 | 波段默认建议 **限价**（或设置项）；市价仍可选 |
| 实盘 / DOM / 跟单 / AI 代下 | 非目标 |

**与计划 / 复盘互链（P0 最小）**

```text
未绑规则 → 规则行链「计划」
有规则   → 标签默认带入；可「仅本单」换
下单成功 → 链本标的复盘（右栏复盘或 /review?symbol=）
仓位工具 → /tools/position?symbol=&entry= ；回跳预填 qty（P1 可加深）
```

### 4.6 RightRail — 复盘

```text
┌─ 本标的 · 近 N 笔模拟 ─────────────────────────┐
│ 筛选：全部 | 有策略标签 | 有偏差标记             │
│ 列表行：时间 · 方向 · 价 · 标签 · 偏差芯片       │
├─ 偏差类型（中性措辞，非情绪诊断）───────────────┤
│ 早于规则退出 | 晚于规则入场 | 超过仓位上限       │
│ 无策略标签 | 触及失效后仍持有（若可判定）         │
├─ 动作 ─────────────────────────────────────────┤
│ [对照当时规则版本]  [开新版本修正规则]           │
│ [打开过程复盘] → /review（跨标的）               │
└────────────────────────────────────────────────┘
```

| 规则 | 说明 |
|---|---|
| 比较口径 | 注明规则版本、样本区间、是否含费用；不把反事实「少赚/多亏」做大标题 |
| 情绪 | 展示用户自选的 emotionTags（若有）；**不**由系统贴「贪婪/恐惧」标签 |
| 空态 | 「本标的暂无模拟成交」+ 链到下单 |

### 4.8 Secondary Tabs（富途式：挂在 QuoteBar 价/涨跌之后）

- 位置：报价条内，紧跟「价 · 涨跌%」，左侧 hairline 分隔；可横向滚动；**不**单独占图上/图下整条灰带
- 下划线 Tab（hairline），不用大胶囊堆
- 默认：**图表**；内容区随 Tab 切换（衍生品 / 新闻 / 财报 / 简介…）
- 美/港：衍生品、资金、卖空、筹码；其它市场按能力隐藏
- **不再**把「AI」作为与新闻同级的主 Tab
- News/Social 情绪：概览内一行或独立次级，不做成 QuoteBar 级进度条
- 分享：居中弹窗渠道网格（非下拉菜单）

### 4.9 提醒

- 概览内一行「提醒：≥ / ≤ [价] [添加]」，或工具条「…」菜单
- 不占独立宽面板

### 4.10 间距与边框（反粗糙）

| Token | 建议 |
|---|---|
| 区块间隙 | 主工作台内部 `0` 或 `1px` 分割；区块之间 `8–12px` |
| 圆角 | 外框 `8px`；控件 `6px` |
| 边框 | 优先分割线，避免框套框 |
| 背景 | 略素的 `--background`；去掉营销径向光晕干扰 |

### 4.11 AI 融合（问股 · 冷静 · 情绪自检）

产品主张落在 **计划核对 + 下单前觉察 + 复盘解释**，不是页脚口号。

#### A. AI 问股

| 项 | 规格 |
|---|---|
| 入口 | QuoteBar；下单区「问这只股票」；手机 FAB 同源 |
| 载体 | `SideDrawer` + 读图 + 对话 |
| 上下文 | 锁定 symbol；可预填「核对当前规则的失效条件是否仍适用」 |
| 禁止 | 抽屉内无「立即市价买入」；不伪造报价 |

#### B. 冷静情景（嵌在「下单」Tab 内）

复用 `AiScenarioPanel` + `/api/ai/scenario`。

**弃用**：独立「模拟草稿」明细卡与下单表单字段重复。

**主推组合**

```text
下单 Tab 上部或可折叠「冷静」
  · regimes（轻）+ calmReminder
  · 筹码：[买·限价] [仓≤x%] [失效价]  → 点击写入表单
  · 「预填到表单」→ 横幅「AI 草稿 · 未提交」+ 可撤销
  · 若计划已绑定规则：预填后校验是否超出规则仓位/失效，超出则提示

下单 Tab 下部
  · 唯一编辑面：表单 + 策略标签 + 情绪自检 + CTA
```

图上挂价（P1）：`watchLevels` / draft.price 虚线，点线写入限价。

#### C. 情绪自检（下单前）

```text
┌─ 下单前自检（可折叠）─────────────────────────┐
│ 今天这笔更像：追涨/FOMO | 恐慌割肉 | 报复交易   │
│               加仓过猛 | 无计划重来 | 以上都不是 │
│ 失效价？ [____]  最多占现金/仓位 __%            │
│ 小字：不阻断下单；写入本笔备注供复盘            │
└────────────────────────────────────────────────┘
```

- 中性「这笔更像…」；禁止「你很贪婪」指责句
- 写入订单 `emotionTags` / `invalidationNote`；复盘与 `/api/ai/review` 优先消费
- 可选本地启发式提示（大涨后买入等）一行 muted，可关

#### D. 衍生品 Tab（次级）

学习向 / 风险语言；个股页 **不做**期权模拟/实盘下单。美/港有链则紧凑 Call/Put 或权证表；无数据空态 + 链 `/tools/options`。与正股 TradePanel 隔离。

#### E. 边界

| 能力 | 位置 |
|---|---|
| AI 问股 | 抽屉 |
| 冷静情景 | 下单 Tab 内 |
| 情绪自检 | 下单 CTA 前 |
| 规则摘要与回放 | 计划 Tab |
| 执行偏差 | 复盘 Tab |
| 舆情 sentiment | 次级/概览（≠ 个人情绪自检） |

| 状态 | UI |
|---|---|
| 报价加载 | 价区骨架；图区骨架 |

| 本标的无成交 | 复盘空态 + 链下单 |

## 8. 验收（UI）

### 布局与精致度

- [ ] 桌面一屏内同时看到：价、主图、右栏（默认计划）、主 CTA 路径清晰  
- [ ] 报价条含规则徽标或「未绑定」；无大卡片指标墙、无 QuoteBar 级 News/Social 条  
- [ ] 图与工具条视觉一体；框线不超过一层  
- [ ] 右栏主 Tab 仅为 `计划 | 下单 | 复盘`（下单亦可走 Dock 抽屉，同一 `TradePanel`）；盘口/分笔不占主 Tab  
- [ ] 涨跌色、`tabular-nums`、深浅色可读；无新增发光/厚阴影  

### 交易抽屉 IA（P0）— 可开发验收清单

> 对应 §4.5.1；过完本表即可判「不再像 demo」。实现以 `src/components/trading/*` 为主。

**票头与身份**

- [ ] 打开交易抽屉时，票头同时可见：代码、名称（可 truncate）、最新价、涨跌%；无「0」/空锚占位  
- [ ] 标题区有清晰 **模拟** 徽标；文案无「实盘」「已买入成功」营销腔  
- [ ] 价与金额一律 `tabular-nums`；涨跌色跟随用户设置  

**策略标签**

- [ ] 下拉选项展示策略**可读短名**（可选版本后缀）；UI **不出现**裸 cuid / 内部 id  
- [ ] 计划已绑定：进入下单时默认选中该策略；可改为「本单不挂标签」或其它策略  
- [ ] 未绑定：规则行 muted 提示 + 链到计划；**不阻断**提交  

**主路径与降权**

- [ ] 账户权益/可用/敞口/单票占比**默认折叠**为一行摘要；展开后才见多格  
- [ ] 情绪自检**默认折叠**；展开后为中性「这笔更像…」芯片，无系统情绪诊断标签  
- [ ] 风险摘要在 CTA 上方可见；无失效价时出现「风险未定义」类中性说明  
- [ ] 「打开仓位工具」链可点到 `/tools/position`（带 symbol/entry 更佳）  
- [ ] 买一/卖一点击可回填限价（限价/相关类型时）  

**提交与闭环**

- [ ] 提交成功：可见「模拟已成交」或「已挂单」反馈 + 入口到本标的复盘或 `/review`  
- [ ] 提交失败：可读错误（含风控拒绝码映射，若已接）；不静默  
- [ ] 订单写入 `strategyTag` / `emotionTags` / `invalidationNote` / `riskSnapshot`（有则），供复盘消费  
- [ ] 全程无 AI「市价立刻买入」按钮；冷静预填须用户再点 CTA  

**回归**

- [ ] 未登录：门控登录，不误提交  
- [ ] 加密/无买卖一时：买卖一区安静降级，不崩票  
- [ ] 文件行数：改动后 `trade-panel` 及相关文件仍 &lt;500 行（超则拆 `trade-ticket-header` 等）  

### 闭环（计划 / 复盘）

- [ ] 无规则时计划 Tab 空态可绑定/选模板，不塞盘口  
- [ ] 有规则时可见入场/退出/仓位/失效摘要  
- [ ] 下单可挂策略标签；冷静为筹码预填 +「预填到表单」，无草稿明细卡，**不自动提交**  
- [ ] 下单前可见情绪自检；中性文案；可选写入订单  
- [ ] P1：本标的回放结果同时展示回撤等风险与收益；含假设一行  
- [ ] P2：复盘可见偏差类型与「开新版本」；不把反事实收益差做主标题  
- [ ] 全程无「市价立刻买入」类 AI 指令按钮  

### 合规与容量

- [ ] 回放/高级行情失败或无权限时安静降级，不造假数据  
- [ ] 盘口/分笔仅可见时轮询

## 9. 线框对照

**改前**

```text
[ Header + 情绪条 + AI ]
[ 图 | 行情(默认) / 下单 / 持仓 ]
[ 次级 Tabs … ]
→ 观察与执行；规则/回放/偏差在别的路由
```

**改后**

```text
[ QuoteBar + 规则徽标 + AI问股 ]
[ 工具条+主图(+规则线) | 计划(默认) / 下单 / 复盘 ]
[          行情折叠可选 | 冷静嵌下单 · 偏差在复盘 ]
[ 次级 Tabs ]
```

**目标动线**

```text
绑定/确认规则（计划）
  → 本标的回放，接受回撤与交易次数（计划）
  → 冷静预填 + 情绪自检 + 挂标签下模拟单（下单）
  → 对照规则版本看偏差（复盘）
  → 开新版本修正（计划/策略页）
```
