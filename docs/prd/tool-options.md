## 1. 背景与目标

在仓位、定投、复利之外，增加**期权学习向估算工具**，覆盖两类高频自学问题：

1. **到期盈亏结构**：权利金、行权价、标的到期价 → 盈亏与打和点（Payoff）。  
2. **理论价格直觉（可选模块）**：用简化 Black–Scholes 看波动率 / 时间对价格的影响（教学用，非报价）。

与产品「冷静投、非下单」一致：只解释结构与量级，**不提供期权链实盘、不推荐开仓方向、不对接券商期权下单**。

**成功标准**

- 用户能在一页内看懂：最大亏损、打和点、到期盈亏随标的价格变化的示意。  
- 合规：明确「模型假设 / 未含费用与提前行权差异 / 部分市场期权不可用」。  
- 与仓位工具互链：算完 payoff 后可去仓位工具限制账户风险（文案引导，非自动）。

## 3. 范围

### 3.1 In Scope（v1）

**模块 A — 到期盈亏（必做）**

- 单腿：买入认购（long call）、买入认沽（long put）。  
- 输入：标的现价（仅展示参考）、行权价 K、权利金 premium、合约乘数（默认 100）、方向已由策略类型决定。  
- 输出：打和点、最大亏损（权利金 × 乘数）、到期盈亏表/示意折线（标的价格从低到高扫描）。  
- 可选：卖出认购 / 卖出认沽（short）——**若做，必须显著提示无限或高亏损风险**；建议 v1 先做买入两侧，卖出为 v1.1。

**模块 B — 理论价（建议 v1 同页第二 Tab，可降级为 v1.1）**

- Black–Scholes 欧式：标的价 S、行权价 K、年化波动率 σ、无风险利率 r、到期时间 T（年）、期权类型 call/put。  
- 输出：理论权利金、Δ（delta）可选；注明「无分红简化、欧式、非实时市价」。

**共同**

- 示例填充、重置、免责、CTA（行情 / 模拟 / 仓位工具）。  
- 纯前端；不拉取期权链 API。

### 3.2 Out of Scope（v1 不做）

- 实时期权链、隐含波动率曲面、券商下单。  
- 美式提早行权精确模型、分红率期限结构。  
- 复杂组合自动定价（跨式、蝶式等）——v1.1+ 用「多腿列表」扩展。  
- 将 AI 自动生成「推荐开哪种期权」。

### 3.3 v1.1 候选

- Short call / short put 盈亏与风险警示强化。  
- 备兑认购：+100 股 −1 call 的合成 payoff。  
- 多腿编辑器（2–4 腿）。  
- URL 参数预填。

## 4. 功能说明

### 4.1 模块 A 输入

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `strategy` | enum | `long_call` | `long_call` \| `long_put`（v1） |
| `spot` | number &gt; 0 | 100 | 现价，用于图上标「当前」参考线 |
| `strike` | number &gt; 0 | 100 | 行权价 K |
| `premium` | number ≥ 0 | 5 | 每股权利金 |
| `multiplier` | number ≥ 1 | 100 | 美股期权常用 100；可改 |

### 4.2 模块 A 公式（每股，再乘乘数得合约盈亏）

```text
// 到期，标的价格为 S_T

long_call payoff_per_share = max(S_T - K, 0) - premium
long_put  payoff_per_share = max(K - S_T, 0) - premium

PnL_contract = payoff_per_share * multiplier

breakeven_call = K + premium
breakeven_put  = K - premium

max_loss_long = premium * multiplier    // 买入权利方
```

扫描轴：`S_T` 从 `min(spot, K, breakeven) * 0.5` 到 `max(...) * 1.5`（边界再钳制 &gt; 0），取约 40–60 个点画折线。

### 4.3 模块 B 输入与公式（若同发）

| 字段 | 说明 |
|---|---|
| S, K, T, σ, r | 标准 BS 输入；σ、r 为小数或百分号，UI 统一百分号 |
| type | call / put |

```text
d1 = [ln(S/K) + (r + σ²/2) T] / (σ √T)
d2 = d1 - σ √T
call = S N(d1) - K e^(-rT) N(d2)
put  = K e^(-rT) N(-d2) - S N(-d1)
```

`N` 为标准正态 CDF。实现可用经过验证的近似（如 Abramowitz–Stegun）或小型依赖；**禁止**在无测试情况下手写不可复核的魔法数。

边界：`T → 0` 回退到内在价值；`σ → 0` 同样回退；非法输入（S,K,T,σ ≤ 0 等）报错。

### 4.4 输出展示

**模块 A**

- 打和点、最大亏损（买入）、到期盈亏图、关键价位表（现价 / 行权价 / 打和点）。  
- 一句结构说明：「买入认购：到期标的需高于打和点才整体盈利」。

**模块 B**

- 理论权利金；可选 Delta。  
- 帮助：「波动率升高，一般抬高权利金（其他不变）」。
