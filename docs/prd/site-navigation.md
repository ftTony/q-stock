## 1. 一句话结构

```text
营销壳（获客顶栏）  →  应用壳（侧栏看盘/模拟）  →  页内工作台（个股/策略详情）
```

主闭环不变：**行情 → 分析/AI → 模拟 → 复盘**；Learn / Tools 在**营销顶栏**可达；进 `/markets` 后切到侧栏应用壳。

### 营销顶栏（首页 / Learn / Tools / 定价…）

```text
[Logo · 标语]     行情 · 理财工具 · 投资知识 · 定价     [主题 · 语言 · 账户]
页脚 CTA 同宽：关于 · 高级行情 · 免责声明（知识/工具/定价已上移顶栏）
                 ↑ MARKETING_SHELL_WIDTH = max-w-6xl / lg:max-w-7xl
```

- **头尾同宽**：`marketing-width.ts` 统一约束。  
- **顶栏**：市场、理财工具、投资知识、定价。  
- **页脚**：只留关于 / 高级行情 / 免责 +「进入行情」；不重复知识/工具/定价。  
- **不宜堆满**：复盘/自选/提醒仍归应用侧栏。

## 3. 规划后 · 推荐信息架构

侧栏控制在 **7±2** 主项；新能力用分组，避免底栏塞爆。

### 3.1 桌面侧栏（建议）

```text
┌─ 钱力股 ─────────────────────────────┐
│ 【看盘】                              │
│  · 行情        /markets               │
│  · 分析        /analysis              │
│  · 自选        /watchlist             │
│                                       │
│ 【练习】                              │
│  · 模拟资产    /portfolio             │  ← 内含持仓 / 今日风险入口
│  · 复盘        /review                │
│  · 规则实验室  /strategies            │  ← 切片 E；未上线可隐
│                                       │
│ 【学习】                              │
│  · 知识        /learn                 │  ← 切片 A
│  · 工具        /tools                 │  ← 切片 B
│                                       │
├───────────────────────────────────────┤
│ 设置 · 关于 ·（可选）高级行情营销链     │
└───────────────────────────────────────┘
```

**折叠态**：只留图标；分组标题隐藏。

### 3.2 手机底栏（建议仍 4～5 格）

优先保留高频（已落地）：

```text
行情 | 自选 | 模拟 | 规则实验室
```

提醒、知识、工具等走页内入口或「更多」抽屉，**不要**全部钉死在底栏。

### 3.3 不进侧栏、页内到达的页面

| 页面 | 如何到达 |
|---|---|
| 个股 `/symbol/[assetType]/[symbol]` | 行情/自选/分析/搜索；侧栏高亮「分析」或「行情」 |
| 个股内：下单 / 冷静 / 盘口 / 衍生品 | **页内 Tabs**，不是新路由主导航 |
| AI 问股 | QuoteBar / FAB **抽屉** |
| 风控设置 | `/settings#risk` 或 `/portfolio`「风控」页签（[risk-control](./risk-control.md)） |
| **价格提醒 `/alerts`** | **自选页「价格提醒」链接**；个股页创建；邮件深链 |
| 策略详情 / 回放 | `/strategies` → `/strategies/[id]` → `.../replay` |
| 高级行情营销 | `/advanced-quotes`（营销或设置链出） |
| 定价 / 登录 | 顶栏账户区；营销壳 |

## 4. 用户主路径（导航视角）

```text
                    ┌─ /learn 文章 CTA ─┐
                    │                   ▼
/markets ──搜/点──► /symbol/... ──下单──► /portfolio ──► /review
    │                  │ 冷静预填            │ 风控摘要
    │                  │ 分享 / 衍生品       │
    ├─ /analysis 对比 ─┘                    │
    │                                       │
    └─ /watchlist ──► /alerts（次级）───────┘

/tools/position ──预填数量──► /symbol/... 下单
/strategies ──回放 / 标签──► /symbol/... 或 /portfolio
```

## 5. 个股页「页内导航」（工作台，非侧栏）

```text
QuoteBar：返回 · 价 · 分享 · 自选 · AI问股
主区：图  |  右栏 Tabs：下单 | 冷静 | 盘口 | 分笔
次级：概览 | 衍生品 | 资金 | … | 新闻 | 财报 | 评论
```

侧栏在个股页保持「分析」（或「行情」）选中即可，**不要**为每个 Tab 加侧栏项。

## 9. 决策摘要

| 项 | 决定 |
|---|---|
| 侧栏分组 | 看盘 / 练习 / 学习 / 事务 |
| 个股 | 页内工作台，不进侧栏一级 |
| 风控 | 设置 + 资产入口，非独立一级导航 |
| 策略 | 一级「规则实验室」；未就绪则 flag 隐藏 |
| 手机 | 底栏保高频；其余进「更多」 |
| 营销 | Learn/Tools 也可从官网进，与应用壳共用路由 |
