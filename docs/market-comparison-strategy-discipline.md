# 市场竞品调查：策略回放、模拟交易与交易纪律

> 调查日期：2026-10-15。本文用于辅助 Q-Stock 产品定位，不是完整的市场穷尽调查。结论基于下列官方产品页面及公开文档；页面未提及某项能力，不代表产品一定不具备该能力。功能可能因地区、账户类型和订阅套餐而异。

## 1. 摘要结论

市场上已有不少产品覆盖策略回测、模拟交易、交易日志、绩效分析或风险监控等单项能力。**功能本身并不新，也不应把“市场上没有竞品”作为 Q-Stock 的定位依据。**

在本次查阅的官方公开资料中，没有确认某个单一产品完整提供以下面向个人投资者的闭环：

```text
制定个人规则 → 历史回放并理解风险 → 模拟交易 → 检查规则遵守情况 → 复盘并修正规则
```

这是基于有限公开资料的观察，不等于证明市场上不存在类似产品，也不代表 Q-Stock 已形成竞争壁垒。Q-Stock 需要通过实际产品和用户验证，证明这个闭环比组合使用多个工具更有价值。

## 3. 对 Q-Stock 的启发

### 3.1 不要把单一功能当护城河

- **回测**：TradingView 等产品已有成熟用户认知和策略测试体验。
- **模拟交易**：券商平台已有账户内模拟功能。
- **交易日志与绩效分析**：TradeZella、Tradervue、Edgewonk 等产品已有不同形式的记录和复盘。
- **规则自动化**：Capitalise.ai 等产品已覆盖规则表达、回测或自动化的一部分。

因此，加入某一项功能可能提高产品完整度，但单靠“有回测”“有 AI”或“有风控”很难构成独特定位。

### 3.2 可验证的差异是流程整合

Q-Stock 可以尝试把以上分散能力连接起来，并让交易纪律成为用户收益之外的主要观察对象：

1. **交易前**：用户写下入场、退出、仓位与风险规则。
2. **历史回放**：展示收益、回撤、连续亏损、成本和样本边界，不只展示表现最好的一项。
3. **模拟执行**：订单关联事先确认的规则版本，草稿由用户检查和提交。
4. **交易后**：对照计划与模拟成交，呈现偏离和执行结果，而非给用户贴心理标签。
5. **规则修订**：修改形成新版本，保留旧版本和旧回放，避免事后覆盖历史假设。

核心价值假设是：**在一个产品内把计划、验证、练习和复盘连起来，是否比用户分别使用图表平台、模拟账户和交易日志更容易坚持。**这需要用户研究和试点验证，不能仅凭产品设计得出结论。

### 3.3 用户群定位

当前更适合把 Q-Stock 定位为：

> 面向个人投资者的策略回放、模拟交易和交易纪律工具；也可探索成为券商零售用户教育或模拟交易体验的能力模块。

这与面向量化团队的研究平台不同。若转向量化团队，需要额外考虑授权清晰的历史数据、组合回测、稳健性研究、团队协作、可复现环境和系统集成，不能仅靠个人交易纪律定位满足其需求。

## 4. 建议的验证指标

如果要验证这个差异化是否成立，优先观察流程和留存，而不是指标数量：

- 用户能否完成「制定规则 → 历史回放 → 查看风险 → 模拟执行 → 复盘」。
- 用户是否重复运行回放、回访策略记录并复盘模拟交易。
- 模拟订单关联预设策略的比例，以及实际执行偏离规则的可观察情况。
- 用户是否理解回撤、成本、数据区间和回测局限。
- 用户是否认为这条闭环比单独使用现有图表、模拟交易和交易日志工具更有帮助，并愿意持续使用或付费。

不要把“用户更少亏损”或“产品消除了情绪”作为未经验证的承诺。用户执行纪律的变化和投资结果受很多因素影响，需要谨慎测量和表达。

## 5. 建议结论

1. Q-Stock 的竞争对象不是单一软件，而是用户现在用来组合完成回测、模拟交易和复盘的工具。
2. 现有市场证明这些单项需求已经存在；差异化应建立在流程整合、规则可追溯、风险透明和执行复盘上。
3. 先完成有限范围、可复现的规则回放与模拟交易闭环，再用用户留存和流程完成情况验证。
4. 不应声称“没有竞品”或“券商无法复制”；较合理的目标是更专注地服务一类用户，并建立持续使用和信任。
5. 本项目的策略回测与账户级风控仍有规划项，参见[交易策略与回测 PRD](./prd/strategy-and-backtest.md)和[模拟盘风险控制 PRD](./prd/risk-control.md)；不能把规划功能描述成已上线能力。
