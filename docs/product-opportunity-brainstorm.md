# 钱力股 / Q-Stock — 产品机会头脑风暴

> 基于[产品现状](./product-status.md)的方向清单。  
> 本文只回答「可以做什么」；「先做什么、怎么验收」见[可落地路线图](./product-roadmap.md)。

## 0. 约束（想点子时别踩）

- 挂在现有闭环上：**看盘 → 分析/AI → 模拟 → 复盘**，避免另开无关产品。  
- 品牌承诺今日是 **学习 / 投研终端**，不是实盘券商；真单对接仅作可选增值或白标需求。  
- 大陆用户需持续保留合规提示（海外标的 / 加密等）。  
- 商业叙事要分清：**C 端使用** vs **源码/部署售卖**，避免官网一锅粥。

## 2. 顺着现有能力长出来的功能

### 2.1 行情侧

- 重新启用或商业化 **扶摇 A 股**  
- **L2 / 高级行情**付费深度（已有 `/advanced-quotes` 叙事）  
- 自选 **收盘摘要 / 周末周报**（worker 已有 digest 雏形）：触及提醒 + 情绪变化  
- 指数 + 热力图加深：板块轮动、资金流向（有稳定数据再做）  
- H5/PWA：锁屏前看自选、加自选一键提醒

### 2.2 分析 / AI 侧（主差异化）

- 情景地图 ↔ 模拟单：无效化条件 → 一键纸面条件单草案（已有雏形）  
- 对比篮持久化 + **分享链接**（2–4 只同行）  
- 交易日志 / 情绪标签结构化（复盘页升级为「过程资产」）  
- 图表解读会话可回看、可导出笔记  
- 邀请配额 → 清晰 **Freemium**（免费额度 / 邀请加量 / BYOK 不限）

### 2.3 模拟盘侧

- 仍可不做真单，但加强：止盈止损、分批建仓、多账户策略标签、「按规则会怎样」回放  
- 学习向 **挑战赛 / 排行榜**（不碰真实资金）——利于裂变

## 3. 产品形态切法（选主线，勿全做）

| # | 形态 | 一句话 | 适合谁 |
|---|---|---|---|
| A | 个人冷静投研终端（C 端） | Learn + Tools + 复盘 + 提醒 | 增长、品牌、SEO |
| B | BYOK 多源行情壳 | 自带长桥/富途/币安 + AI Key | 已有券商账号的活跃用户 |
| C | 源码 / 私有化 / 白标 | 多语言壳 + 行情路由 + AI；可去品牌 | 工作室、教育机构、小团队 |
| D | 投教 SaaS | 老师发课 → 学员模拟 → 统一复盘看板 | 培训机构、KOL 课堂 |
| E | 合规「海外市场观察台」 | 信息聚合 + 强免责 + 多语言 | 东南亚 / 华人圈观察需求 |

**不建议轻易做的**：把默认产品改成「能下真单」——合规与品牌定位都会变。

## 5. 商业模式选项（可并行，官网叙事要分清）

### 5.1 C 端 Freemium

- 免费：行情 L1、自选、模拟、有限 AI  
- 增长：邀请加 AI 额度  
- 付费 / 不限：订阅加额度，或用户 BYOK 绕过平台配额  
- 可选加价：L2、扶摇深度、邮件周报高级版

### 5.2 源码 / 部署一次性

- 已有 `/pricing`：源码、部署、定制（CNY 一次性叙事）  
- 可加：部署文档包、主题白标、去掉品牌、私有化环境变量清单  
- 售后：升级包 / 工时制而非无限 SaaS 运维

### 5.3 投教 / 白标（中期）

- 在 A 或 C 验证后再开：班级、作业、统一复盘看板  
- 计价：按班级席位或按年授权

## 6. 明确不做或后置（防发散）

| 项 | 原因 |
|---|---|
| 默认开通实盘下单 | 合规、牌照、客诉与品牌承诺冲突 |
| 无数据的「资金流向 / 聪明钱」大屏 | 易沦为假深度，损害信任 |
| 同时主推三条 GTM（C 端订阅 + 源码卖断 + 投教 SaaS） | 官网与研发注意力都会碎 |
| 为凑功能而做社区帖流 | 与冷静投、过程复盘主线弱相关 |

---

## 7. 选题时的简单打分（内部用）

对每个候选功能问四句：

1. 是否强化「看 → 想 → 练 → 复盘」？  
2. 是否复用已有数据源 / worker / AI，而不是新堆一座烟囱？  
3. 两周内能否做出可演示的垂直切片？  
4. 对 C 端转化或源码转化，哪一条更直接？

高分进[路线图](./product-roadmap.md)；低分留在本文档作备选池。
