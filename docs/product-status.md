# 钱力股 / Q-Stock — 产品现状盘点

> 与当前代码库对齐的产品能力快照，供路线规划与对外介绍使用。  
> 更新口径：以仓库实现为准，不以营销文案为准。

## 1. 定位

| 项 | 说明 |
|---|---|
| 产品 / 品牌 | Q-Stock（界面品牌：钱力股 / Qianli Gu） |
| 形态 | 响应式 Web + H5（同一套 Next.js）；含 PWA manifest |
| 一句话 | 面向个人投资者的多市场学习型投研终端：看盘、分析、模拟、复盘 |
| 明确不是 | 实盘券商 App；不做投资建议；不承诺荐股 |

主站首页 `/` 为营销落地页；真实产品入口为 `/markets`。

核心闭环（已具备骨架）：

```text
看盘 / 自选 / 提醒  →  分析 / AI  →  模拟交易  →  AI 过程复盘
```

旁路能力：多源行情 + BYOK、在线 Free/Pro（兑换码 / 可选 Stripe）、源码/部署销售页（`/pricing` 分栏）。

## 2. 已上线能力

### 2.1 行情与标的

| 能力 | 路由 / 入口 | 说明 |
|---|---|---|
| 市场看板 | `/markets` | 美 / 港 / A / 加密；热股涨跌；搜索；KPI；行业热力图（非加密）；港股 IPO；情绪条；约 45s 静默刷新；心形加自选 |
| 个股详情 | `/symbol/[assetType]/[symbol]` | 报价头 + 吸顶迷你栏；日/季/年 K；MA/EMA/BOLL/RSI/MACD；盘口统计；模拟下单；价格提醒；资讯/财报/公告/公司/高管/评论/情绪/AI |
| 自选 | `/watchlist` | CRUD（含 A 股）；搜索添加；迷你走势 / 实时报价 |
| 顶栏指数 | 产品壳 | 美 / 港 / A 指数轮播 |

**资产类型**

- `stock` — 美股  
- `hk` — 港股（如 `00700`）  
- `cn` — A 股  
- `crypto` — 主流币（内部如 `BTC`）

### 2.2 分析与 AI

| 能力 | 路由 / 入口 | 说明 |
|---|---|---|
| 同行分析 | `/analysis` | 行业 → 同行板；对比篮 2–4 只；基本面指标；AI 同行对比 |
| AI 套件 | 个股 / 复盘等 | 趋势分析、图表解读、个股对话（会话入库）、情景地图（可带纸面草案）、对比、复盘 |
| AI 配额 | 账户 / 邀请 / Pro | Free 终身约 5 次 + 邀请 +5；Pro 每月 100；BYOK 不占平台配额 |

产品语气偏「冷静投」：强调结构、价位、无效化条件，避免直接出下单指令。

### 2.3 模拟盘、提醒、设置

| 能力 | 路由 / 入口 | 说明 |
|---|---|---|
| 模拟组合 | `/portfolio` | 账户 KPI、持仓、挂单、成交、重置；侧栏资讯/情绪 |
| 过程复盘 | `/review` | 基于纸面成交的日/周 AI 复盘；情绪标记 + 清单笔记 |
| 价格提醒 | `/alerts`（次级） | ≥ / ≤ 邮件提醒；worker 回穿再武装。**不占一级导航**；自选页入口 + 个股页创建 |
| 设置 | `/settings` | 语言、主题、涨跌色；长桥/富途/币安/OKX BYOK；多厂商 AI Key；邀请码；可选邮件凭证 |

### 2.4 账户与运营壳

- 鉴权：邮箱密码、忘记/重置密码；可选 Google / GitHub OAuth；邀请码增长（AI 配额）
- 营销页：落地页、`/about`、`/disclaimer`、`/pricing`、`/advanced-quotes`（说明 L2 未开）
- UX：可折叠侧栏、H5 底栏、亮暗色、CN/US 涨跌色
- 后台：`npm run worker`（提醒 + 模拟限价/止损成交 + 美股收盘自选摘要）；可选 `quote-ws` 推送行情

### 2.5 国际化

UI 10 语：`en`（默认无前缀）、`zh-CN`、`zh-TW`、`ja`、`ko`、`fr`、`de`、`es`、`ms`、`th`。  
偏好入库枚举仅 `zh-CN` / `zh-TW` / `en`，其余 UI 语种保存时映射为 `en`。

## 3. 数据源与集成

| 角色 | 链路 |
|---|---|
| 股票行情 | 长桥 ↔ 富途 → Finnhub（设置里可选偏好券商） |
| 加密行情 | 币安 ↔ OKX → Finnhub |
| 凭证模型 | 平台 env Key 优先，否则用户 BYOK（加密存库） |
| 资讯 | 长桥 → 富途 → Finnhub |
| 基本面 / 财报 / 公司 | 以 Finnhub 为主（券商内容有则补充） |
| 情绪 | Adanos（美股/加密较好；港股常降级） |
| AI | Vercel AI SDK：DeepSeek / OpenAI 兼容 / Gemini / Anthropic |
| 邮件 | Resend 或 SMTP |

**已写但未开**

- 扶摇（同花顺）：客户端代码在，路由层硬禁用，设置页隐藏  
- L2 / 高级行情：营销页存在，产品侧为 L1 取向  
- 实盘券商：`src/lib/broker` 为 Phase 2 stub（`getBrokerGateway()` → `null`）

## 6. 差异化（相对「纯行情站」）

1. **一壳四市场**：美 / 港 / A / 加密，统一导航与个股页语言。  
2. **券商级 failover + BYOK**：平台 Key 或用户自带；偏好 + 自动切换。  
3. **冷静向 AI**：图表解读 / 对话 / 情景 / 对比 / 复盘，强调结构与无效化，而非喊单。  
4. **规则 → 回放 → 模拟 → 复盘闭环**：策略标签挂单、过程与情绪复盘；规则实验室做教学向回放（非量化平台）。  
5. **区域产品细节**：涨跌色、多语言、邀请增长、大陆合规提示。  
6. **双线 GTM**：C 端终端 + 源码/部署包装（`/pricing`）+ 高级行情叙事。  
7. **可交付形态**：Docker、健康检查、凭证加密、提醒 worker、可选行情推送、PWA。
